Data, privacy & backup

This starter version stores data securely in this browser on this device. Offline entry works. True cloud sync across devices needs a cloud database connection (for example, Supabase) and its project credentials; it is not active yet. Do not enter bank passwords, UPI PINs or OTPs here.

PIN lock protects the app screen. Keep your backup file somewhere safe. Clearing browser data may erase records unless backed up.

Cloud sync setup is the next development step. We'll connect your own private database before enabling multi-device access.
